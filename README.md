# Ecommerce

Учебный проект с классами товаров и категорий.

Классы `Product` и `Category` находятся в `src/`. Файл `main.py` импортирует их
и показывает пример использования.

## Возможности

- `Product` хранит название, описание, цену и количество товара на складе.
- `Category` хранит название, описание и список товаров.
- `Category.category_count` хранит общее число созданных категорий.
- `Category.product_count` хранит общее число товаров в списках созданных категорий. Количество единиц на складе при этом не суммируется.

## Классы товаров

- Абстрактный класс `BaseProduct` требует, чтобы товары поддерживали строковое представление (`__str__`) и сложение (`__add__`).
- `Product` реализует эти методы. `Smartphone` и `LawnGrass` наследуются от него и добавляют свои характеристики.
- `LoggingMixin` при создании товара выводит в консоль имя его класса и параметры. Он работает для `Product` и его наследников.

Вывод при вызове `Product("Чай", "Чёрный чай", 80, 15)` выглядит так.

```text
Product('Чай', 'Чёрный чай', 80, 15)
```

## Запуск

Для запуска нужны Python 3.14 и Poetry. Выполняйте команды из корня проекта.

```bash
poetry install --no-root
poetry run python main.py
```

## Тесты

```bash
poetry run python -m pytest
```

Команда для обновления [HTML-отчёта о покрытии](htmlcov/index.html).

```bash
poetry run python -m pytest --cov=src --cov-report=term-missing --cov-report=html
```
